# Генератор DXF для волновой зубчатой передачи (Harmonic Drive)

## Что это
Программа рассчитывает эвольвентную геометрию волновой зубчатой передачи
и экспортирует контуры в DXF для последующего изготовления
(лазерная резка, 3D-печать, ЧПУ) или визуализации в CAD.

**Важно:** используется приближённая, но геометрически корректная инженерная
модель (эвольвентный профиль + деформация генератора волн по косинусоидальному
закону). Реальные волновые передачи используют запатентованные сопряжённые
профили и требуют инженерной валидации (прочность, ресурс, беззазорность).
Эта программа подходит для визуализации, обучения и прототипов,
но не заменяет промышленный инжиниринг.

## Установка (один раз)

Откройте проект в PyCharm, затем в терминале PyCharm выполните:

```
pip install -r requirements.txt
```

## Запуск

Откройте `main.py` и нажмите Run (зелёная стрелка) в PyCharm.

Результат появится в папке `output/`:

- `flexspline_cylindrical.dxf` — гибкое колесо, цилиндрическое (для изготовления)
- `flexspline_deformed.dxf` — гибкое колесо, деформированное рабочее (эллиптическое)
- `circular_spline.dxf` — жёсткое колесо (неподвижное, с внутренними зубьями)
- `wave_generator_cam.dxf` — кулачок генератора волн
- `assembly_preview.dxf` — все контуры вместе, для проверки зацепления
- `preview.png` — картинка для быстрого просмотра без CAD-программы

## Как изменить параметры передачи

Все исходные данные находятся в начале файла `main.py`, в блоке
"ИСХОДНЫЕ ДАННЫЕ":

| Параметр | Описание |
|---|---|
| `MODULE` | модуль зацепления, мм |
| `Z_FLEXSPLINE` | число зубьев гибкого колеса (чётное) |
| `NUM_WAVES` | число волн генератора (обычно 2) |
| `Z_CIRCULAR_SPLINE` | число зубьев жёсткого колеса (по умолчанию = Z_FLEXSPLINE + NUM_WAVES) |
| `PRESSURE_ANGLE_DEG` | угол зацепления, градусы (стандарт 20) |
| `FLEXSPLINE_WALL_THICKNESS` | толщина стенки гибкого колеса, мм |
| `CIRCULAR_SPLINE_RIM_THICKNESS` | толщина обода жёсткого колеса, мм |
| `WAVE_GENERATOR_BORE_DIAMETER` | диаметр отверстия под вал генератора волн, мм |

После изменения параметров просто запустите `main.py` заново —
файлы в `output/` перезапишутся.

## Передаточное отношение

Для стандартной волновой передачи с неподвижным жёстким колесом и выходом
на гибком колесе передаточное отношение считается как:

```
i = Z_FLEXSPLINE / (Z_CIRCULAR_SPLINE - Z_FLEXSPLINE)
```

Оно выводится в консоли после запуска программы.

## Структура файлов

- `gear_geometry.py` — расчёт эвольвентного профиля зубьев (наружное и внутреннее зацепление)
- `deformation.py` — деформация гибкого колеса генератором волн
- `dxf_export.py` — экспорт контуров в DXF
- `main.py` — точка входа, исходные данные, сборка всех контуров
